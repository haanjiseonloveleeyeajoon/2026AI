# [PRD] 전국 어린이 보호구역 지도 애플리케이션

## 1. 프로젝트 개요 (Overview)
본 프로젝트는 `전국어린이보호구역표준데이터.csv` 데이터를 기반으로 전국 어린이 보호구역의 위치, 시설 종류, CCTV 설치 여부, 관할 경찰서 등의 정보를 지도 상에서 직관적으로 확인하고 필터링할 수 있는 대화형 지도 웹 애플리케이션의 개발 요구사항 정의서입니다.

---

## 2. 핵심 기능 요구사항 (Key Requirements)

### F-1. 위치 기반 마커 표시 (Geographic Marker Rendering)
- **요구사항**: CSV 파일 내 `위도` 및 `경도` 좌표 데이터를 파싱하여 지도(Leaflet.js 기반) 위에 마커로 표시합니다.
- **세부사항**:
  - 총 14,000여 건의 대용량 마커를 안정적으로 렌더링하기 위해 **마커 클러스터링(Marker Clustering)** 기술을 적용합니다.
  - 좌표 데이터 누락/오류 항목은 사전 예외 처리하여 앱 정상 작동을 보장합니다.

### F-2. CCTV 설치여부별 마커 색상 구분 (Color-coded Markers)
- **요구사항**: `CCTV설치여부` 컬럼 값에 따라 마커 색상을 다르게 표현합니다.
- **세부사항**:
  - **파란색 마커 (Blue Marker)**: CCTV 설치 구역 (`CCTV설치여부 == 'Y'`)
  - **빨간색 마커 (Red Marker)**: CCTV 미설치 구역 (`CCTV설치여부 == 'N'` 또는 미설치 상태)

### F-3. 사이드바 필터링 및 동기화 (Sidebar Filtering & Live Sync)
- **요구사항**: 사용자가 원하는 조건으로 지도 데이터를 필터링할 수 있는 인터랙티브 사이드바를 제공합니다.
- **세부사항**:
  - **시설종류 필터**: 어린이집, 유치원, 초등학교, 특수학교, 학원 등 (다중 선택/전체 선택 지원)
  - **CCTV 설치여부 필터**: 전체 / 설치(Y) / 미설치(N) 선택 (라디오 버튼 또는 토글 칩)
  - **실시간 통계 표출**: 필터 적용에 따른 검색된 보호구역 총 건수 및 CCTV 설치 비율 표시

### F-4. 마커 클릭 시 상세 정보 팝업 (Interactive Info Popup)
- **요구사항**: 지도 상의 마커를 클릭했을 때 대상 시설의 상세 정보가 담긴 Popup을 출력합니다.
- **표시 항목**:
  1. **대상시설명** (`대상시설명`)
  2. **주소** (`소재지도로명주소` 우선 표출, 부재 시 `소재지지번주소`)
  3. **보호구역 도로폭** (`보호구역도로폭`)
  4. **관할경찰서명** (`관할경찰서명`)
  5. *(부가표시)* 시설종류 뱃지 및 CCTV 설치여부/설치대수

## 3. 데이터 명세 및 파싱 (Data Specification)

### 3.1 원본 데이터 사양
- **파일명**: `전국어린이보호구역표준데이터.csv`
- **인코딩**: `EUC-KR` (CP949)
- **전체 레코드 수**: 약 14,648 건

### 3.2 주요 필드 매핑 테이블
| CSV 컬럼명 | 데이터 타입 | 필수 여부 | 사용 목적 / UI 연결 |
| :--- | :--- | :--- | :--- |
| `위도` | Float | 필수 | 지도 마커 Latitude 좌표 |
| `경도` | Float | 필수 | 지도 마커 Longitude 좌표 |
| `시설종류` | String | 필수 | 사이드바 필터 / 팝업 뱃지 |
| `CCTV설치여부` | String (Y/N) | 필수 | 마커 색상 구분(파랑/빨강) / 사이드바 필터 |
| `대상시설명` | String | 필수 | 팝업 타이틀 |
| `소재지도로명주소` | String | 선택 | 팝업 주소 (1순위) |
| `소재지지번주소` | String | 선택 | 팝업 주소 (2순위) |
| `보호구역도로폭` | String/Number | 선택 | 팝업 보호구역 도로폭 정보 |
| `관할경찰서명` | String | 선택 | 팝업 관할 경찰서 정보 |

## 4. 기술 스택 및 라이브러리 (Tech Stack)

- **Frontend**: HTML5, CSS3, JavaScript (ES6 Vanilla JS / Modern Web Standards)
- **Map Engine**: Leaflet.js (v1.9.4) - OpenStreetMap 타일 레이어 연동 (API 키 불필요)
- **Performance**: Leaflet.markercluster (마커 클러스터링)
- **Data Parser**: PapaParse (v5.4.1) 또는 브라우저 `TextDecoder('euc-kr')` 파싱 엔진

---

## 5. UI/UX 디자인 가이드라인 (Design System)

1. **레이아웃 구조**:
   - 좌측: 검색 및 필터 컨트롤 사이드바 (넓이 360px)
   - 우측: 지도 뷰포트 (전체 화면 꽉 차게 구성)
2. **비주얼 스타일**:
   - 다크 톤 배경과 투명감이 느껴지는 Glassmorphism 디자인 적용
   - 파란색(`Y` - `#2563EB`)과 빨간색(`N` - `#EF4444`)의 높은 명도 대비로 직관적 가시성 제공
3. **인터랙션**:
   - 마커 마우스 오버 시 호버 효과 및 클릭 시 팝업 애니메이션
   - 필터 조작 시 마커 클러스터 재계산 및 렌더링 애니메이션
