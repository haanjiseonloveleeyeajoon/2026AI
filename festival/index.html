Vercel 프로젝트 구조 & 기술 개요

https://festival-01.vercel.app/ 프로젝트의 시스템 아키텍처와 주요 기술 스택을 소개합니다.

Vercel Edge Deployment

전 세계 CDN Edge 네트워크를 통한 빠른 퍼스트 페인트(FCP) 로딩 구현. 축제 현장에서 동시 접속자가 폭증해도 끊김 없는 초고속 반응속도를 보장합니다.

Responsive Mobile First UX

축제 방문객의 95% 이상이 스마트폰으로 접속함에 착안하여, 한 손 조작과 직관적 카드 탭 UI, 터치 스탬프 기능을 최우선으로 설계했습니다.

Real-Time Data State

푸드트럭 혼잡도, 공연 일정 변경, 실시간 방명록 피드 등 변화하는 축제 현장 데이터를 실시간으로 동기화할 수 있는 모듈형 상태 관리 시스템.
