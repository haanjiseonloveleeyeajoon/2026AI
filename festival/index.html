03

핵심 기능 명세 (Key Features & Specifications)

3.1실시간 공공데이터 연동 및 폴백 시스템
  • 데이터 출처: 공공데이터포털 부산광역시 축제 서비스 API (getFestivalKr)
  • API 프록시 엔드포인트: /api/festivals
  • 캐싱: 10분 주기 메모리 캐싱으로 API 호출 최적화
  • 폴백(Fallback): 공공데이터포털 트래픽 초과·점검 시 검증된 대표 축제 정제 데이터로 자동 전환
3.2탐색 및 필터링 (Search & Filtering)
  • 지역별 필터: 부산 16개 구·군(해운대구, 수영구, 중구, 영도구, 동래구 등) 독립 필터링 및 카운트 표시
  • 시기별 필터: 1월~12월 월별 개최 축제 분류 및 전체보기
  • 키워드 실시간 검색: 축제명, 장소, 구·군 명칭 실시간 쿼리 매칭
  • 정렬 기능: 날짜순(최신순), 축제명순 정렬
  • 찜한 축제 전용 뷰: 브라우저 localStorage 기반 개인화 찜 목록 관리
3.3멀티 뷰 모드 (Multi-View System)
  • 그리드 뷰 (Grid View): 카드형 에디토리얼 레이아웃 — 대표 이미지, 뱃지, 날짜, 장소 제공
  • 리스트 뷰 (List View): 가로형 리스트 패턴으로 긴 설명과 정보를 빠르게 스캔
  • 대화형 지도 뷰 (Map View): Leaflet 기반 커스텀 마커 지도, 클릭 시 인포 팝업 및 상세 보기 연동
3.4축제 상세 모달 (Festival Detail Modal)
  • 시각적 히어로 영역: 고화질 축제 이미지 및 구·군 식별 뱃지
  • 상세 정보 패널: 기간, 운영 시간, 이용 요금, 문의 전화(tel: 바로 연결), 주소 복사
  • 캘린더 저장: .ics 파일 생성 → 구글/애플/아웃룩 캘린더 연동
  • 공유하기: 현재 축제 URL 클립보드 복사
  • 공식 홈페이지 바로가기: 외부 링크 이동
3.5Gemini AI 맞춤형 여행 가이드 (AI Tour Guide)
  • 엔드포인트: /api/ai-recommendation (Serverless Function)
  • AI 모델: Google GenAI gemini-2.5-flash
  • 맞춤 동선 생성: 선택 축제·구·군·월별 조건 기반 관광 동선, 교통 팁, 주변 맛집·명소 추천
  • 프리셋 버튼: 해운대 당일치기 코스, 데이트 코스 추천 등 자주 묻는 질문 원클릭 제공
